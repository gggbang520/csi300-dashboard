# 全球市场全景数据库

这是基于 GitHub Pages 的静态版全球市场研究数据库。

## 访问方式
发布到 GitHub Pages 后，访问：
https://gggbang520.github.io/csi300-dashboard/

## 核心模块
- 全球核心指数与地区市场
- 沪深300全量成分与全球重点指数成分
- 公司分类：一级行业 / 二级行业 / 细分方向
- 行情、周度涨跌、成交额、换手、市值、PE/PB、资金流
- 公司基础档案
- 宏观经济指标
- 经济术语
- 周度研究分析
- 1周 / 1个月 / 3个月研究性情景区间
- JSON / CSV 导入与历史导出
- GitHub 版本历史

## 数据更新方式
每周将新的 JSON 更新到 data/current.json 后，GitHub Pages 自动发布。
网页也支持浏览器内直接导入我提供的 JSON/CSV。

## 数据原则
动态行情字段必须标注数据日期和来源。空值表示尚未可靠核验，不代表0。
预测区间属于研究记录，不构成收益保证。

旧版 Streamlit 程序已备份在 legacy/，不再作为主页。
